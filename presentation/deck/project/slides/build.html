工程

怎么做的。

DESKTOP

Go + MyGo

一套代码三个桌面系统；转换引擎在 internal/convert，自带 FFmpeg、PDFium

ANDROID

Kotlin + Compose

原生转换引擎；液态玻璃底栏基于 AndroidLiquidGlass

iOS

SwiftUI

原生转换引擎；工程由 XcodeGen 的 project.yml 描述

每个平台，都用真引擎测

转换矩阵在各平台的真实引擎上逐一跑；只在有 FFmpeg 的平台测 FFmpeg 路线

PNG

WAV

CSV

RELEASE

推送标签即发布

v* 标签触发 GitHub Actions，构建全部平台并发到 Releases

技术上：桌面端用 Go 写，基于 MyGo 框架；Android 用 Kotlin 和 Jetpack Compose；iOS 用 SwiftUI。测试方面，我们让转换矩阵在每个平台的真实引擎上跑一遍。发布是自动的：推送 v 开头的标签，GitHub Actions 就会构建所有平台并发布。
