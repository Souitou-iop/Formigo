Formigo ships FFmpeg as a separate program (bin/ffmpeg), which it runs to
convert video and sound. FFmpeg is not part of Formigo's own code.

Windows (x64) and Linux (x64): FFmpeg 8.1, "lgpl" static build by BtbN
